## 📌 Overview

This project analyzes daily air quality readings from CPCB monitoring stations across India, cleans and audits the data for quality issues, produces 10 visualizations of pollution patterns, and trains a classifier that predicts the AQI category for a given set of pollutant readings.

It's split into three stages:

1. **Data pipeline** — load, audit, and clean 29.5K raw records
2. **EDA** — 10 saved visualizations covering geography, time, and pollutant relationships
3. **Modeling** — a Random Forest classifier predicting AQI_Bucket, plus an interactive Streamlit app to explore trends and get live predictions

## 🧹 Data Cleaning Approach

Rather than blanket-imputing every gap, the pipeline is deliberately conservative:

- Rows with no `AQI` value are dropped (unusable for ranking or modeling).
- Missing pollutant readings are filled using **city-level median only** — if a city never measured a pollutant at all (e.g. some cities have zero real PM10 or O3 readings), that stays `NaN` rather than being fabricated from other cities' data.
- A **physical-consistency check** flags impossible values: negative readings, duplicate city+date rows, and PM2.5 > PM10 (PM2.5 is a physical subset of PM10, so this should never happen — it did in ~9% of rows with both values present, concentrated in cities with the weakest raw PM10 coverage, which is itself a useful data-quality finding).
- An anomaly check compares mean vs. median per city/pollutant to separate **sustained sensor issues** from a handful of one-off spike days.

## 🤖 AQI Prediction Model

A Random Forest classifier predicts the `AQI_Bucket` category (Good / Satisfactory / Moderate / Poor / Very Poor / Severe) from same-day pollutant readings + month.

- **Accuracy:** ~80% on a held-out 20% test split (6-class problem)
- **Top predictive features:** PM2.5, PM10, CO, O3, NO
- Full metrics (per-class precision/recall, confusion matrix) are written to `outputs/model_report.json` after each run.

This is intentionally a same-day classification task (nowcasting from pollutant sensor readings), not a next-day forecast — a natural next step is reframing it as a time-series forecasting problem using lagged features.

## 🖥 Interactive Dashboard

`app.py` is a Streamlit app with three views:

- **City Trends** — pick a city and pollutant, see the monthly trend and summary stats
- **State Comparison** — states ranked by PM2.5, national seasonal pattern
- **AQI Predictor** — enter pollutant readings and get a live predicted AQI category from the trained model

```bash
pip install -r requirements.txt
```



## 📁 Dataset

CPCB city-day air quality data, 2015–2020, 26 cities across 21 states/UTs. Source: [Kaggle — Air Quality Data in India](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india).

| Column | Description |
|---|---|
| `City` | City name |
| `Date` | Date of reading |
| `PM2.5`, `PM10`, `NO`, `NO2`, `NOx`, `NH3`, `CO`, `SO2`, `O3`, `Benzene`, `Toluene`, `Xylene` | Pollutant concentrations |
| `AQI` | Composite Air Quality Index |
| `AQI_Bucket` | AQI category label (Good → Severe) |

## 💡 Key Findings

- Certain northern Indian cities/states consistently show the highest PM2.5 and PM10 levels.
- Pollution peaks sharply in winter months (Nov–Feb) — consistent with crop burning and low-wind conditions.
- PM2.5 and CO are the strongest single predictors of overall AQI (correlation ~0.66–0.68).
- ~9% of rows with both PM2.5 and PM10 measured show PM2.5 > PM10, a physical impossibility concentrated in cities with sparse PM10 coverage — flagged as a data-quality issue rather than silently modeled around.
- **Ahmedabad ranks 5th nationally by average PM2.5** (~68 µg/m³), behind only Patna, Delhi, Gurugram, and Lucknow. This is a genuine finding, not a data artifact — Ahmedabad has one of the most complete records in the dataset (2,009 of 2,009 possible days, tied with Delhi and Mumbai for the highest coverage), its PM2.5 is stable across all six years rather than driven by a few spike days, and it independently corroborates external reporting: WHO's 2014 report and CPCB's 2001 ranking both placed Ahmedabad among India's top 5 most PM2.5-polluted cities, driven by coal power plants, vehicle emissions, and open burning at the Pirana dumping ground. It's a useful reminder that Delhi-centric media coverage of India's air quality crisis doesn't reflect the full picture.
- Not every city has equally reliable coverage, though: smaller cities like Aizawl (113 days), Kochi (162), and Shillong (310) have far fewer recorded days than the six cities with full coverage (2,009 days each), so city-level averages for those are based on thinner samples and should be read with more caution.
